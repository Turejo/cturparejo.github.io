# Sacolomina - Tienda de Videojuegos

Sitio web oficial de Sacolomina, una tienda de videojuegos online con catálogo de juegos variados.

## Características

- **Diseño Responsive**: Se adapta a dispositivos móviles y escritorio
- **Catálogo de Productos**: Galería de videojuegos con precios y descripciones
- **Menú Interactivo**: Menú hamburguesa para dispositivos móviles
- **Páginas Principales**: Inicio, Privacidad, Contacto y Login
- **Diseño Moderno**: Interfaz limpia y atractiva
